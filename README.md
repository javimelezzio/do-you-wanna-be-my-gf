# do-you-wanna-be-my-gf 💌

This is a simple HTML/CSS/JavaScript project made by an amateur student.  
It’s a small interactive “love letter” experience created for learning and fun.

## ✨ Features
- Envelope intro → letter → heart screen
- Floating hearts with click explosion
- Live “time since” counter

## 🚀 Run locally
Just open `index.html` in a browser (or use VS Code Live Server).

## 🎨 Customize
- **Text:** edit `index.html`
- **Styles/background:** edit `styles.css`
- **Phrases + start date:** edit `script.js` (`frases` array + start date in `actualizarContador()`)

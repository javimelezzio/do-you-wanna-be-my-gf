# do-you-wanna-be-my-gf 💌

An interactive romantic web project built with **HTML, CSS, and JavaScript**.  
It was created for fun, creativity, and sharing affection through code.

## ✨ Features
- Animated envelope that opens with a flap effect.
- A card asking: *Do you want to be my girlfriend?*
- Playful **No** button that moves around the screen.
- Expanding **Yes** button that grows to cover the screen.
- A love letter popup in a new tab.
